# AgentFeed

עסקים ישראליים בפורמט שסוכני AI קוראים — מוצרים, מחירים, זמינות ופרטי העסק.

**כל עסק כאן הצטרף באישור מפורש שלו**, וכל דף אומר גם מה העסק *טרם פרסם*,
כדי שאף סוכן לא ימלא את החסר בניחוש.

בעל עסק שרוצה לצאת — הודעה אחת והכול נמחק.

הריפו הזה מכיל את הדפים הציבוריים בלבד. הוא נבנה אוטומטית; אין לערוך אותו ביד.
