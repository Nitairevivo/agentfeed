חיבור לקוח חדש

אתר, לוח בקרה ומנתח AI ללקוח, בצעד אחד. מתאים לכל אתר: וורדפרס, Wix, שופיפיי או קוד רגיל.

1להדביק באתר של הלקוח

שורה אחת, לפני התגית </body>. היא סופרת ביקורים ולחיצות על וואטסאפ, טלפון, מייל וסל, כולל איזה מוצר. בלי עוגיות ובלי פרטים אישיים.


    
    
      
  • וורדפרס: תוסף WPCode, אחר כך Code Snippets, ואז Header & Footer. מדביקים ב-Footer.
    • 
      
  • Wix: הגדרות, ואז Custom Code. מוסיפים קוד, בוחרים Body - end ו-All pages.
    • 
      
  • שופיפיי: Online Store, ואז Themes, ואז Edit code. בקובץ theme.liquid מדביקים לפני </body>.
    • 
      
  • אתר בקוד: בכל עמוד, לפני </body>.
